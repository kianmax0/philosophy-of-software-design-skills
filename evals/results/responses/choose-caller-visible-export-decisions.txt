Evidence and recommendation

`include_header` changes the exported rows in a caller-visible way, and the request expressly says to preserve header control. Keep it as the one caller-facing option. Its current `True` default is reasonable for an ordinary CSV export, while callers can set it to `False` when they need headerless output.

The fixture defaults `date_format` to `"iso"`, and the request calls the date representation required. Assuming ISO is that required representation, make ISO a module-owned invariant and remove `date_format` from the caller-facing signature. This keeps callers from accidentally violating the required output contract. If the externally required representation is not ISO, substitute that required representation internally; the fixture and task do not establish another value.

For the stated CSV use, keep comma as the module default and remove `delimiter` from this interface. No consumer needing another delimiter is shown. Keep `null_text=""` and `quote_all=False` as module defaults as well; the supplied evidence does not show that this caller has information requiring a choice. Those policies can be changed centrally if the CSV contract later establishes different values.

```python

    ...
```

Inside the module, the implementation would apply the CSV contract consistently: comma delimiter, ISO dates (under the assumption above), empty null text, and `quote_all=False`. Those implementation details should not appear as caller choices for this use.

The meaningful exceptional caller that needs a headerless file can turn off the header without reimplementing export logic. No evidence was provided for a meaningful alternate delimiter, null spelling, quoting policy, or date representation, so this review does not recommend retaining those options on this caller's interface.

The fixture contains no such callers, so their existence is unknown; check actual call sites before applying the recommendation. The assumption that ISO is the required date representation should be confirmed against the governing CSV contract before implementation.
